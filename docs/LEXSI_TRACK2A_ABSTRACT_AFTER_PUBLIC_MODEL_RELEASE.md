# PolicyProof AI — Track 2a abstract AFTER verified public adapter release (DRAFT ONLY)

PolicyProof AI is a multilingual safety-benchmark and evaluation pipeline for evidence-grounded answers to fictional policy questions in English, Norwegian and Arabic. We measure required JSON validity, source citation identifiers, unsupported-question abstention and adversarial prompt-injection failures. Our Track 2 pipeline uses Lexsi CuratorKIT for synthetic dataset curation and AuditKIT for strict evaluation, with a separate AlignTune 40-step LoRA fine-tuning experiment.

We published source-pinned synthetic benchmark materials, including an original 48-case development set and a 72-case adversarial challenge. In a later owner-run study, Tiny Aya Global produced 72 source-linked responses on that challenge: 58/72 schema-valid outputs, 11/72 strict exact reference matches and 6/12 correct canonical abstentions on unsupported questions. Original GPU provenance is self-reported and the results are not human semantic accuracy judgments.

The native AlignTune 40-step adapter was trained on a separate 78-example synthetic dataset. In a matched, previously inspected 48-case development comparison with the unchanged Tiny Aya base, schema-valid responses increased from 14/48 to 48/48, and raw expected citation IDs from 31/39 to 39/39 answerable cases. However, exact supported-answer matches remained 0/39; correct unsupported abstentions fell from 4/9 to 2/9, while unsupported claims rose from 5/9 to 7/9. Thus, **formatting improved while an important safety behavior regressed**; we do not claim improved factual accuracy or model safety. A deterministic inference-time guard helped abstention and formatting in a separate CPU replay but did not establish source entailment.

The open research contribution is a reproducible multilingual benchmark, original-source hashes, detailed negative findings, source-controlled evaluation notebooks and an experimental adapter-only release under the applicable noncommercial upstream terms. Its source Tiny Aya base model remains gated. We provide a public dataset collection, model/adapter collection, source repository and research report for reproduction. Independent human semantic review and training-time base-revision attestation remain incomplete.
