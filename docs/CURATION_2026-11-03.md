## Important limitations and issues

1. **Data is not ready for a final scientific claim.** It has only 78 synthetic examples, and the same 12 short policy paragraphs are repeated in each prompt. Most questions are template variants. Deduplication did not remove any near-duplicate questions, and there is no human-reviewed semantic quality label.
2. The run used the tool's schema, exact deduplication and text cleaning, but **did not use LLM grounding/hallucination judges, diversity gates, or semantic filtering**. Those should not be claimed.
3. The generated dataset README config descriptions contain export hashes that **do not match** the actual files. The dedicated checksums.txt entries *do* match all five listed files. For provenance, rely on actual file hashes and checksums.txt and document the conflicting README metadata.
4. The manifest's source_files list is empty; lexsi_provenance.json references the Colab training JSONL path. The GitHub source fixtures and exact repository revision are needed to reproduce original rows.
5. Exporting the same 78 rows in Alpaca and ShareGPT formats does **not** create 156 independent training examples.
6. **No model has yet been trained with AlignTune.** GPU training, model architecture support and resulting checkpoints are still unverified.
