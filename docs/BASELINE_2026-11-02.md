## Re-score in Colab without re-running the GPU

With the original dataset and report present in `/content/PolicyProof-AI`:

```bash
cd /content/PolicyProof-AI
git pull --ff-only
python -m scripts.rescore_report \
  --report artifacts/tiny_aya_base_unseen_policy.json \
  --dataset data/unseen_policy_test.jsonl
python -m scripts.human_review \
  --predictions artifacts/tiny_aya_base_unseen_policy.json \
  --cases data/unseen_policy_test.jsonl \
  --output artifacts/tiny_aya_blind_review.csv
```

**Do not redo model inference solely to correct the evaluator.** Avoid training on, or selecting prompts/hyperparameters using, these 48 exposed holdout cases. Because the full benchmark has been inspected, treat it as a **development diagnostic** for future model improvements and build a new independent, human-reviewed final holdout before reporting improvement. This prevents choosing a winner based on repeated use of the same test set.
